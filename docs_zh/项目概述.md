## EdgeCrab 项目架构概览

### 项目定位
EdgeCrab 是一个 **AI-native 终端代理**，类似于 hermes-agent 的 Rust 实现。它是一个多平台智能体，支持 CLI TUI、网关（多消息平台）、ACP（VS Code 集成）等多种运行模式。

### 核心架构（Crate 依赖图）

```
edgecrab-types        ← 核心类型：Message, Role, ToolCall, ToolError 等
     ↑
edgecrab-security     ← 安全层：路径安全、SSRF 防护、命令注入扫描
     ↑
edgecrab-tools        ← 工具注册表 + 30+ 工具实现
     ↑
edgecrab-core         ← Agent ReAct 循环、对话、压缩、路由
     ↑
edgecrab-cli, edgecrab-gateway, edgecrab-acp, edgecrab-migrate, edgecrab-plugins
```

### 主要 Crate 说明

| Crate | 职责 |
|-------|------|
| **edgecrab-types** | 核心类型定义（Message, Role, ToolCall, ToolError, 错误类型等） |
| **edgecrab-security** | 安全模块：路径安全、SSRF 防护、命令扫描、代理支持 |
| **edgecrab-state** | SQLite WAL + FTS5 会话存储 |
| **edgecrab-tools** | 工具注册表（`ToolHandler` trait）+ 30+ 工具实现（文件操作、终端、Web、浏览器、记忆、技能等） |
| **edgecrab-core** | Agent 核心：ReAct 对话循环、上下文压缩、提示构建、模型路由、目标管理、Mission Steering |
| **edgecrab-cli** | ratatui TUI、CLI 子命令、皮肤引擎、42+ 斜杠命令 |
| **edgecrab-gateway** | 消息平台网关（Telegram, Discord, Slack, WhatsApp, Signal 等 17+ 平台） |
| **edgecrab-acp** | ACP JSON-RPC 2.0 stdio 适配器（VS Code 集成） |
| **edgecrab-proxy** | OpenAI 兼容代理（本地 provider 桥接） |
| **edgecrab-plugins** | 插件系统（WASM + Lua） |
| **edgecrab-cron** | Cron 作业调度引擎 |
| **edgecrab-lsp** | LSP 集成 |
| **edgecrab-migrate** | 从 hermes-agent 迁移配置/记忆/技能 |

### 关键设计特点

1. **ReAct 循环** (`conversation.rs`): 核心的工具调用循环，支持流式响应、上下文压缩、学习反射
2. **Agent Builder 模式** (`agent.rs`): `AgentBuilder::new("model").provider(...).tools(...).build()`
3. **工具自动注册**: 使用 `inventory` crate 实现编译时注册
4. **Mission Steering**: 支持 HINT/REDIRECT/STOP 三种实时操控模式
5. **持久化目标** (Ralph Loop): 跨会话的目标管理
6. **上下文压缩**: 基于 LLM 的摘要 + 结构化的降级方案
7. **模型目录**: YAML 驱动的模型配置，支持 13+ 提供商
8. **安全模型**: 多层防护（路径、网络、命令、提示注入）

### 技术栈
- **Rust 2024 edition** (requires 1.95.0+)
- **异步运行时**: Tokio
- **TUI**: ratatui + crossterm
- **LLM 后端**: edgequake-llm (0.6.25)
- **数据库**: SQLite (rusqlite) + FTS5
- **HTTP**: reqwest + axum (网关)
- **构建**: cargo workspace
